# drpy3 宿主对接指南（跨语言适配规范）

> 读者：要用任意语言（Java/Kotlin-Android、Dart-Flutter、Python、Go、C#、Rust…）给 drpy3 写宿主（壳子）的开发者。
> 引擎本体是纯 JS ESM（`dist/drpy3.js` 可读单文件），宿主只需要：一个能跑 ESM 的 JS 引擎 + 按本指南注入宿主环境。
> 配套阅读：[drpy3-设计文档.md](drpy3-设计文档.md)（§2 运行时对接矩阵 / §5.4 异步档位 / §7 HostEnv / §10 返回值与桥接）、
> [drpy2-移植对接指南.md](drpy2-移植对接指南.md)（drpy2 契约考古，drpy3 向后兼容的依据）。

---

## 0. TL;DR —— 最小对接清单

1. **随包分发 5 个引擎文件**（同目录，缺一不可）：

```
drpy3.js                    可读单文件引擎（调试用；也可只发压缩版）
drpy3.esm.min.js            压缩单文件引擎
drpy3-peer.js               peer 装载链（原生全局守卫 → 库包 → 恢复）
drpy3-globals-capture.js    无依赖快照/垫片（必须在库包之前求值——peer 链已保证顺序）
drpy-core-lite.min.js       库全局包（CryptoJS/jinja/模板/pako/gbkTool/JSEncrypt/NODERSA/JSON5/JSONPath）
```

2. **注入 5 个必选宿主函数**：`req / pdfh / pdfa / pd / pdfl`（签名见 §2）。
3. **注入 2 个按档位需要的函数**：`syncReq`（档 C 同步宿主，load2x 必需）/ `loadAsset`（源带 wasm/模块资产时必需）。
4. **按异步档位接线**：档 A 原生 Promise（Node/quickjs-ng/browser）；档 B 宿主泵 Promise job；
   档 C 全同步（req 阻塞实现，await 立即完成）——**源代码三档无感**。
5. **调用六环节**：`init → home → category → search → detail → play`（另有 homeVod/proxy/action/sniffer/isVideo），
   返回值为 **JS 对象**（TVBox 结构），宿主在边界自行 `JSON.stringify`。
6. **挂载源环境全局（§9，必做）**：库全局（CryptoJS 等）+ `exposeRuntimeGlobals(rt)` 裸名工具面——
   不做则大面积加密源报 `No crypto library available`。同步泵引擎另须做线程隔离（§10）。

## 1. 引擎装载

```js
// ESM 宿主：直接静态/动态 import
const drpy3 = await import('./drpy3.js');
const { Runtime, defineSource } = drpy3;         // drpy3.default 亦可用（drpy2 消费习惯）
```

- 引擎与库包必须**同目录**（`drpy3.js` 内部 `import './drpy3-peer.js'` → peer 再引 `./drpy-core-lite.min.js`）。
- peer 链会在库包求值**前**快照原生全局（WebAssembly/fetch/TextEncoder/console.error），
  库包求值后恢复——防止库内 polyfill 污染宿主底层（如 Node undici 依赖原生 WebAssembly）。
  **宿主不要自行 import 库包**，一律经引擎间接使用。
- 引擎需要宿主提供：`globalThis`、ESM import、`TextEncoder/TextDecoder`、`WebAssembly`
  （无原生 wasm 的引擎 capabilities.wasm 报 none，源可据此降级）。

## 2. HostEnv 注入契约（唯一注入面）

```js
const rt = new Runtime({
    // ═══ 必选五件套（缺注入时 rt.check() 打印清单、capabilities 标 missing）═══
    req(url, options) {},                  // HTTP。同步或异步皆可，引擎统一 await。返回 {content, headers}
    pdfh(html, parse, baseUrl) {},         // jsoup：选择器取单值（'body&&.title&&Text'）
    pdfa(html, parse) {},                  // jsoup：选择器取元素列表（返回元素 HTML 字符串数组）
    pd(html, parse, baseUrl) {},           // jsoup：取值 + URL 补全
    pdfl(html, parse, listText, listUrl, myUrl) {},  // jsoup：整列表一次解析 → ['标题$链接', ...]

    // ═══ 可选（缺省走框架内置兜底）═══
    batchFetch(items) {},                  // 并发批量：[{url, options}] → 按序响应文本数组；缺省框架 req+Promise.all 兜底
    joinUrl(base, path) {},                // URL 拼接；缺省 WHATWG URL 语义
    store: {get(ns,k,def), set(ns,k,v), delete(ns,k)},  // 持久 KV 介质；缺省内存 Map。ns=源 key（框架拼命名空间）
    log(...args) {},                       // 日志出口；缺省 console.log
    getProxy(isPublic) {},                 // 本地代理地址；缺省 'http://127.0.0.1:9978/proxy?do=js'
    loadAsset(path) {},                    // 读源目录资产（wasm/模块文件）→ string|Uint8Array；无兜底
    env: {...},                            // 壳子自定义配置透传
    action: true,                          // action 通道开关（false 时 capabilities.action=false，源据此降级）
    actionTimeoutMs: 60000,                // action 专用长超时（默认 60s）
    syncReq(url, options) {},              // 档 C 同步 HTTP 桥（load2x 老源片段必需，见 §5）
    evalModule(code, path) {},             // 模式 A 原生 ESM 装载钩子（源含相对 import 时启用）
    lifecycle: {idleTTL:120, maxHot:16, memUsage:()=>0..1, watermark:0.7, watermarkTarget:0.5},
    pinList: ['_源key'],                   // 钉住不驱逐的源
    engine: 'quickjs-ng 1.x', version: '1.0',
    wasm: 'native',                        // native|polyfill|none（缺省自动探测 globalThis.WebAssembly）
});
```

### 2.1 `req` 契约（最重要）

```js
req(url, options) → { content, headers }   // 出错不抛：返回 {content:'', headers:{error:'...'}}
```

| options 字段 | 说明 |
|---|---|
| `headers` | 请求头普通对象（引擎已合并实例基线/调用级/本次三层，见 §4） |
| `method` | GET（缺省）/POST/PUT/DELETE/HEAD |
| `timeout` | 毫秒（建议设硬上限） |
| `encoding` | 响应解码字符集（缺省 utf-8；响应头 charset 优先） |
| `body` | 字符串请求体 |
| `data` | 对象：GET 时拼 query；非 GET 时序列化为请求体 |
| `buffer` | 缺省→文本；`1`→content 为 **Uint8Array**（二进制，wasm/TS 流用）；`2`→content 为 base64 |
| `redirect` | `0` 禁止跟随 30x |
| `withHeaders` | drpy2 兼容标记：引擎的 reqCookie/同步桥自行拼装 headers+body，宿主通常无需特殊处理 |

- `headers` 必须是可写普通对象（引擎/源可能追加属性）。
- **同步或异步皆可**：返回 Promise 即档 A；同步阻塞返回即档 C——引擎统一 `await`。

### 2.2 `pdfh/pdfa/pd/pdfl` 契约

jsoup 语义四件套，**切勿手写正则解析器**——参考实现见本仓库 `cli/htmlParser.js`
（自 drpy-node 生产实现移植，cheerio 版），其他语言照语义移植：
选择器 `&&` 分段（`body&&.list&&a&&href`）、末段取值器（`Text`/`Html`/属性名）、
`:eq/:lt/:gt/:first/:last` 索引、`||` 属性回退、`pd` 自动 URL 补全、
`pdfl` 批量整表解析（`'标题$链接'` 数组）。

### 2.3 `syncReq` 契约（档 C 必需）

```js
syncReq(url, options) → {content, headers}   // 必须【同步阻塞】返回
```

load2x 兼容层的 drpy2 老源片段是同步代码（`request(url)` 直接消费返回文本），
引擎无法 await——宿主必须提供同步 HTTP 实现（参考：子进程 curl、引擎内置同步 socket、JNI 阻塞调用）。
仅 `load2x` 老源使用；drpy3 新源永远走异步 `req`。

## 3. Runtime 调度契约

```js
const rt = new Runtime(hostEnv);
rt.check();          // → {missing:[...], fallbacks:{...}, wasm, engine}（构造时已自动打印）
rt.capabilities;     // 冻结能力表：{req/pdfh/pdfa/pd/pdfl: host|use-override|builtin|missing,
                     //    batchFetch/joinUrl: builtin|host|use-override, store: host|memory-fallback,
                     //    log/getProxy: builtin|host|use-override, loadAsset: host|missing,
                     //    wasm: native|polyfill|none, action: bool, engine, version}
rt.use({pdfh: ...}); // 运行时覆盖任意注入项（粒度到函数）
rt.sweep();          // 手动触发生命周期治理（LRU/水位/maxHot 驱逐；平时自动）

const src = await rt.load(sourceCode, {
    key: '_唯一标识',      // 源 key（store 命名空间/生命周期登记）
    path: '源.js',         // 相对路径（signature 热更/模式 C 模块解析基准；不传则不做热更比对）
    extend: {...},         // init 透传
    mode: 'cjs',           // 强制模式 C（内置 CJS shim）；缺省自动判定
    drpy3: true,           // 强制不走 load2x 自动路由
});
const src2x = rt.load2x(drpy2Code, {key: '_old'});  // 显式装载 drpy2 老源（自动串行）
```

引擎自动判定装载形态：`lang:'dr2'` 或 `var rule =` → load2x 兼容层；否则按 ESM 求值
（宿主有 `evalModule` → 模式 A 原生 ESM；源仅 `require`/简单 import → 模式 C shim；无模块能力
且源含相对 import → 报错提示走预打包模式 B）。

### 3.1 六环节调度（返回 JS 对象，宿主边界 JSON.stringify）

| 方法 | 签名 | 返回结构 |
|---|---|---|
| `init(extend)` | 初始化（冷→热复温） | 无（内部完成 rule 定稿/栏目表预热） |
| `home(filter)` | 分类+筛选 | `{class:[{type_id,type_name}], filters:{...}}` |
| `category(tid, pg, filter, extend)` | 一级列表 | `{page, pagecount, limit, total, list:[vod]}` |
| `search(wd, quick, pg)` | 搜索 | 同 category |
| `detail(id)` | 二级详情 | `{list:[vod]}`，vod 含 `vod_play_url: '第1集$url1#第2集$url2$$$线路2…'` |
| `play(flag, id, flags)` | 播放地址 | `{parse:0/1, jx:0/1, url}` 或 `{parse:0, urls:[线路名,url,…], header}`；url 可能带保留前缀（见 §3.3） |
| `proxy(params)` | 本地代理 | 五元组 `[status, contentType, content, headers?, toBytes?]` |
| `action(action, value)` | 源内交互 | **纯文本 = 宿主应直接 toast 展示**（源内动作反馈的标准通道，如能力探针源）；结构化对象 = 动作配置继续分发（§3.1 下详） |

- `vod_id` 透传契约：含 `rule.detailUrl` 的源，引擎在分类时加「分类$」前缀、进 detail 前剥除
  （drpy2 同语义往返）；无 detailUrl 的源（drpyS 式任意文本 id）**原样透传不加工**。
- `proxy` 五元组 `toBytes`：缺省→文本回包；`1`→content 为 base64 转字节；`2`→content 为 URL，
  宿主 302 重定向；`3`→content 为 URL，宿主内联流式 pipe（Range 透传）。
- `action`：引擎自动挂专用长超时（默认 60s）；`capabilities.action=false` 时源不输出交互条目。
- 所有异常包装为 `Drpy3Error`：`{stage, rule, error, hint, source}`（`hint` 为内置修复建议）——
  宿主日志/上报请取该结构化字段，勿裸抛引擎栈。

### 3.2 错误与超时

- 引擎层不吞六环节异常：失败时抛 `Drpy3Error`（有 `stage/rule/error/hint` 字段与 `toJSON()`）。
- `action` 通道：60s（`actionTimeoutMs` 可调）超时自动失败。
- 生命周期：实例空闲 `idleTTL`(120s)/`maxHot`(16)/内存水位(0.7→0.5) 自动驱逐；
  `signature`（源文件内容指纹）变化 → 下次调用前自动重建；有 in-flight 调用的实例不驱逐。
- **同步 req 的宿主注意**：档 C 下 `req` 阻塞事件循环——多源并发调用请由宿主串行化/线程化。

### 3.3 播放前缀识别（宿主播放器侧义务）

`play` 返回的 `url` 可能带保留前缀——宿主按前缀路由，**勿一律起视频播放器**：

| 前缀 | 形态 | 宿主行为 |
|---|---|---|
| `novel://` | `novel://` + JSON `{title, content}`（宽松解析序：先直接 parse、失败再 URL decode；content 按 `
` 分段） | 阅读视图，**不加载视频播放器** |
| `pics://` | 图片/漫画载荷 | 图片浏览模式 |
| `music://<直链>` | 音频直链声明剥离 | 音频接管（后台播放/媒体通知），剥离后按直链播 |

无前缀走常规视频（`parse:1` 时宿主先网页嗅探）。小说/漫画源即靠 `novel://`/`pics://` 输出。

## 4. 引擎内部行为（宿主无需实现，了解即可）

- **请求头三层合并**（框架负责，宿主 req 只管透传）：`本次 options.headers > 调用级 fetchParams.headers > 实例基线 headers`；
  UA 常量名（'MOBILE_UA'/'PC_UA'/'IOS_UA'/'UC_UA'）在任何一层出现都会解析为真实 UA；
  缺省补 UA=MOBILE_UA、Referer=站点首页。
- **js: 片段**：AsyncFunction + `with(scope)` 受控执行，drpy2 全部老名字
  （request/fetch/post/pdfh/pdfa/pd/jsp/setResult/VOD/VODS/TABS/LISTS/MY_URL/input/fetch_params/MOBILE_UA/log/print/lib/ctx…）
  参数化注入，不触碰宿主 globalThis；片段内 `request()` 返回**响应文本**（drpy2 老语义）。
- **声明式默认引擎**：源只写 `{meta, rule}` 时，home/category/search/detail/play 全部由框架按
  drpy2 语义执行（class_parse/url 渲染[fyclass/fypage/区间/filter_url×jinja2]/json:jsp:jq: 规则/二级 js:/播放 lazy）。
- **wasm 托管**：`ctx.lib.wasm.load('./x.cjs'|bytes|URL)` 识别 emscripten 工厂
  （module.exports 或挂 globalThis 的脚本形态）、提供垫片、等就绪、按路径/字节哈希缓存（Runtime 级跨实例存活）。
- **store 隔离**：宿主介质按 `(源key, 键)` 存取，框架拼命名空间——宿主不用自己拼 RKEY。

## 5. 异步三档（宿主按能力自选，源代码无感）

| 档 | 宿主形态 | 效果 | 额外工作 |
|---|---|---|---|
| **A** | Node / quickjs-ng / 浏览器 / 事件循环完备的引擎 | 真并发 IO | 无 |
| **B** | 嵌入式绑定可泵 Promise job（JS_ExecutePendingJob 循环 + 异步回填） | 完整体 | job 泵 |
| **C** | 传统同步宿主（如 python-quickjs 同步桥） | 功能 100%，无并发收益 | `syncReq` 同步 HTTP 桥（load2x 老源必需） |

> 任何能跑 drpy2 的壳子都能跑 drpy3：先按档 C 接入拿功能，再按需升档拿并发。

## 6. 语言适配要点（对接矩阵详见设计文档 §2）

| 语言/环境 | 引擎载体 | 要点 |
|---|---|---|
| **Node.js** | 原生 ESM | 参考本仓库 `cli/node-host.mjs`（完整 HostEnv 实现：node:http req、jsoup 解析、curl syncReq） |
| **Android (QuickJS/Javet)** | quickjs | ESM import + 文件分发；wasm 走引擎原生；UI 层注入 Java 实现的 req/pdf 四件套 |
| **Flutter (qjs so)** | quickjs 定制版（FFI），档 B | **现役形态（DsPlayer，2026-09-27 起；fjs 已退役下架）**：引擎整体跑在独立 worker isolate（§10），req 经桥到 Dart HttpClient；pdf 四件套随 bundle 内置；`declareNewModule` 做 evalModule；每入口刷新栈基线（线程迁移，qjs_update_stack_top） |
| **Python (quickjs 绑定)** | quickjs | 同步桥（档 C）：`syncReq` 用 requests；json 桥接进出 |
| **Go (goja)** | goja | goja 无原生 wasm——capabilities.wasm=none，源降级；ESM 支持有限优先用模式 B 预打包 |

通用建议：**模式 B 预打包**（`cli/drpy3-build.mjs 源.js`）对无模块能力引擎最省事；
压缩版 `drpy3.esm.min.js` 适合内嵌资源分发。

## 9. 源环境的全局注入义务（库全局 + 裸名工具面）

**机制**：源体经 loader 中性求值（`new AsyncFunction('defineSource', 'lib', body)`）——源体内
**只有这两个形参可见**，任何其他名字的可见性都取决于宿主引擎的 globalThis。两个义务层级：

### 9.1 库全局（必做，不做则大面积源炸）

源生态大量使用裸名 `CryptoJS`（探测链 `typeof CryptoJS !== 'undefined'` → `_nodeCrypto` →
`require('crypto')`，qjs 类环境后两条恒落空）——**库包（drpy-core-lite）里现成对象在库包求值期
挂到 globalThis 即可**：

```js
globalThis.CryptoJS = CryptoJS;   // 库包内部对象（求值期可取）
globalThis.JSEncrypt = JSEncrypt;
globalThis.pako = pako;
globalThis.gbkTool = gbkTool;
globalThis.模板 = 模板;            // drpy2 模板基建
```

不做则加密/签名类源（如七猫/七星短剧聚合）报 `No crypto library available`，home 全空
（DsPlayer qjs 宿主真机实锤，2026-09-28）。**勿挂 cheerio**（若引擎已注入 C 版 cheerio，
覆盖是纯 JS 化退化）；`jinja`/`JSONPath` 由各自脚本 side-effect 自挂，勿重复。

### 9.2 裸名工具面（dr2 迁移兼容，强烈建议）

引擎导出 `exposeRuntimeGlobals(rt)`（Runtime 创建后调用一次）：把「Runtime 级单例、无调用态」
的纯工具提为 Context 全局，dr2 老源作者的写法习惯在源内**裸名直接可用**——

| 组 | 裸名 |
|---|---|
| crypto 9 | `md5` `base64Encode` `base64Decode` `gzip` `ungzip` `aesX` `desX` `rc4` `rsaX` |
| text 3 | `cut` `encodeStr` `decodeStr` |
| utils 10 | `joinUrl` + **`urljoin`（dr2 老名）**、`getHome` `urlencode` `encodeUrl` `buildUrl` `buildQueryString` `forceOrder` `是否正版` `urlDeal` |
| parse 5 | `pdfh` `pdfa` `pd` `pdfl` `jp` |
| UA 4 | `MOBILE_UA` `PC_UA` `IOS_UA` `UC_UA` |
| 日志 | `print` `log` → HostEnv.log |

**刻意不挂**（设计红线，挂了跨调用串态）：`req`/`request`/`post`/`reqCookie`/`batchFetch`/`download`
（绑定每次调用的 ctx headers）、`store`/`cache`（实例态）、`parseRule`（要 ctx）、`getProxyUrl`
（dr2 是字符串常量、dr3 是 async 函数，语义不同易误导）——这些**只走 `ctx.*`**。同名不覆盖
（库全局/宿主注入优先）。

## 10. 线程与隔离模型（同步泵引擎必读）

框架与库自身无线程要求，但**源代码可能含纯 CPU 密集段**（wasm 解密循环、大 JSON 处理、
大 base64 编解码）——同步泵类引擎（quickjs 系：求值到 await 点让出，纯 CPU 段一口气跑完）
执行这些段会**同步占死执行线程直到完成**（秒级～十几秒）。

- **引擎执行必须隔离在非 UI 线程**（worker isolate / 子进程 / 专用线程）。反例（DsPlayer
  央视频实锤）：引擎在 UI isolate 执行时，wasm 代理每段解密冻结整个壳子；搬入 worker
  isolate 后解密期间 UI 零卡顿，段解密 ~2.7s 顺畅推进。
- **线程迁移宿主（如 Dart isolate/线程池调度）的栈基线陷阱**：quickjs 的栈检查基线
  （stack_top）在引擎创建线程记录；isolate 迁移 OS 线程后基线与求值线程的栈地址差随机
  超过许可线 → **假 stack overflow**（512MB 许可仍炸，md5 级浅调用即触发）。根治 =
  **每次进入引擎求值前以当前线程重算基线**：qjs_ultra 提供 `qjs_update_stack_top(rt)`
  导出（quickjs 定制版 JS_UpdateStackTop 包装），其 `QuickjsEngine` 已在执行链汇聚点
  自动调用。标准 quickjs 宿主需自行 patch（或保证引擎绑定固定线程）。
- **多 Runtime 实例并存安全**：回调表按 JSContext 注册（per-engine），实例间互不干扰
  （同 isolate 内多实例共享一个执行线程，天然串行）。

> 检验方法：装载能力探针类源（大量 ctx.md5/CryptoJS 冒烟调用）在 worker 内连续执行，
> UI 线程零卡顿、无误报 stack overflow 即达标。现成探针源见
> [docs/samples/dr3能力探针.js](samples/dr3能力探针.js)——8 组 70 项逐函数实测，
> 点击即输出 typeof + 冒烟结果，兼作各宿主全局注入的验收工具。
